# opencode-session-tokens

Плагин для OpenCode, который показывает расход токенов и стоимость текущей сессии: панель с детализацией (входящие, исходящие, рассуждения, кэш, ходы, стоимость), строку статуса внизу окна и пилюлю `Σ <сумма>` рядом с индикатором контекста в композере.

## Возможности

- **Боковая панель «Токены сессии»** — суммарные токены сессии по категориям: входящие, исходящие, рассуждения (reasoning), кэш (чтение/запись), количество ходов и стоимость в `$`.
- **Пилюля в композере** — компактный индикатор `Σ 12.3k` рядом с «NN% ctx»; обновляется автоматически (~каждые 2 секунды), клик открывает панель. Показывает подробности в подсказке при наведении.
- **Строка статуса внизу окна** — краткая сводка `Σ in … · out … · $…` для текущей сессии.
- **Слэш-команда `/tokens`** («Показать токены сессии») — открывает/закрывает панель.
- **Локализация** — встроенные переводы на английский и русский языки.
- **Устойчивое чтение данных** — получение сообщений сессии через SDK OpenCode с перебором нескольких методов API (`session.messages`, `session.message.list`, `session.context`); при отсутствии токенов в ответе показывает ключи сообщений для отладки.

## Технологический стек

- **TypeScript** (strict, ES2022) — язык плагина.
- **[SolidJS](https://www.solidjs.com/) ≥ 1.9** — реактивный UI GUI-части.
- **[@opencode/plugin](https://opencode.ai/docs/build/plugins) ≥ 2.2.0** — SDK плагинов OpenCode (серверная и GUI-части).
- **[Vite](https://vite.dev/) 7 + vite-plugin-solid** — сборка GUI-бандла через пресет `@opencode/plugin/gui/vite`.

Пакеты `@opencode/plugin` и `solid-js` объявлены как опциональные peer-зависимости: в рантайме их предоставляет само приложение OpenCode.

## Установка и настройка

### Требования

- Node.js и npm (Vite 7 требует Node.js ≥ 20.19 или ≥ 22.12).
- OpenCode Desktop (GUI-часть плагина работает в десктоп-приложении).

### Установка как плагина OpenCode

Плагины, опубликованные в npm или лежащие локально, подключаются в `opencode.json(c)` (глобальном `~/.config/opencode/opencode.json` или проектном):

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-session-tokens"
  ]
}
```

Либо из локальной директории (например, если репозиторий склонирован рядом):

```jsonc
{
  "plugins": [
    "./opencode-session-tokens"
  ]
}
```

Плагины под `.opencode/plugins/` загружаются автоматически без настройки.

### Сборка из исходников

```bash
# клонирование репозитория
git clone https://github.com/alexandr777git/opencode-session-tokens.git
cd opencode-session-tokens

# установка зависимостей (включая dev-зависимости для сборки)
npm install

# сборка GUI-бандла → dist/gui-experimental.cjs
npx vite build

# режим разработки: пересборка при изменениях
npx vite build --watch
```

> **TODO:** в `package.json` нет секции `scripts` — команда сборки вызывается напрямую через `npx vite build`. При желании добавьте скрипт `"build": "vite build"`.

## Использование

1. Соберите плагин (`npx vite build`) и подключите его в `opencode.json(c)`, как описано выше.
2. Откройте OpenCode Desktop и начните сессию.

Примеры работы с плагином:

- Слэш-команда в композере:

  ```text
  /tokens
  ```

  Открывает боковую панель с детализацией токенов текущей сессии.

- Пилюля в композере рядом с индикатором контекста показывает суммарные токены сессии:

  ```text
  Σ 12.3k
  ```

  Наведение — подробности по категориям; клик — открыть/закрыть панель.

Внизу окна постоянно отображается сводка вида `Σ in 4 512 · out 1 203 · $0.0310`.

## Структура проекта

```text
├── src/
│   ├── index.ts                # серверная часть: регистрация плагина (id: session-tokens)
│   └── gui.tsx                 # GUI-часть: панель, статус-строка, /tokens, пилюля композера
├── dist/
│   └── gui-experimental.cjs    # собранный GUI-бандл (экспорт ./gui-experimental)
├── vite.config.ts              # конфигурация Vite с пресетом gui() из @opencode/plugin/gui/vite
├── tsconfig.json               # настройки TypeScript (strict, JSX: solid-js)
└── package.json                # манифест пакета, exports и peer-зависимости
```

Счётчик токенов целиком живёт в GUI-части (`src/gui.tsx`); серверная часть (`src/index.ts`) нужна только для регистрации плагина с явным `id`.

## Конфигурация

- Переменные окружения и опции плагина не используются.
- Единственная точка настройки — подключение плагина в `opencode.json(c)` (см. [Установка и настройка](#установка-и-настройка)).
- Язык интерфейса (en/ru) подставляется автоматически из встроенных переводов `i18n` в `src/gui.tsx`.
